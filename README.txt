# Escola sem Violência — Website educativo

## Conteúdo
- `index.html`: estrutura e conteúdo do website.
- `style.css`: cores, tipografia, ilustrações CSS e adaptação a telemóveis/computadores.
- `script.js`: menu móvel, separadores de recomendações e questionário interactivo.

## Como abrir no telemóvel
1. Extraia o ficheiro ZIP.
2. Abra a pasta `violencia_entre_alunos`.
3. Toque em `index.html` e escolha um navegador (Chrome, por exemplo).
4. Para publicar, carregue os três ficheiros (`index.html`, `style.css` e `script.js`) para a raiz de um repositório GitHub e active GitHub Pages.

## Nota
O website é educativo e não recolhe nem envia dados. Os links externos abrem fontes institucionais. O questionário funciona localmente no navegador.
